Operating Systems Lab Manual: CPU Scheduling

Aim of the Experiment

To design, implement, and analyze fundamental CPU Scheduling algorithms in Operating Systems including First-Come, First-Served (FCFS), Shortest Job First (SJF Non-preemptive), Shortest Remaining Time First (SRTF Preemptive), Round Robin (RR), and Multi-Level Feedback Queue (MLFQ). To quantitatively compare the scheduling criteria: Completion Time (CT), Turnaround Time (TAT), Waiting Time (WT), CPU Utilization, and System Throughput.

Standard Evaluation Metrics & Mathematical Formulas

1. Turnaround Time (TAT) = Completion Time (CT) - Arrival Time (AT)
2. Waiting Time (WT) = Turnaround Time (TAT) - Burst Time (BT)
3. Response Time (RT) = Time CPU First Allocated - Arrival Time (AT)
4. CPU Utilization (%) = (Total CPU Busy Time / Total Execution Time) × 100
5. System Throughput = Total Number of Processes Completed / Total Execution Time

Key Algorithm Trade-offs

  • FCFS (First-Come, First-Served): Simplest non-preemptive scheduling policy. Suffers from the Convoy Effect where short processes are stuck waiting behind a massive CPU-bound process.
  • SJF (Shortest Job First): Non-preemptive. Gives minimum average waiting time for a given set of processes. Can cause starvation of long burst processes if shorter processes keep arriving.
  • SRTF (Shortest Remaining Time First): Preemptive version of SJF. Preempts the current process whenever a newly arrived process has a shorter remaining burst time.
  • Round Robin (RR): Preemptive policy designed for time-sharing systems. Allocates a fixed time quantum ($Q$) to each process in cyclic FIFO order. Balances responsiveness across all processes.
  • MLFQ (Multi-Level Feedback Queue): Dynamic multi-tier scheduler. Separates processes based on their CPU-burst characteristics. Interactive I/O-bound jobs remain at top priority; long CPU-bound jobs drop to lower priority. Aging prevents starvation.

Algorithmic Pseudo-Code

Pseudo-Code: Shortest Job First (SJF Non-Preemptive)
currentTime = 0, completed = 0, n = TotalProcesses
Sort processes initially by Arrival Time (AT)

While completed < n:
    candidates = all processes with (AT <= currentTime AND completed == false)
    
    If candidates is empty:
        currentTime = next minimum AT among uncompleted processes
        Continue

    // Select candidate with minimum Burst Time (BT)
    currentProcess = candidate with min(BT) [break ties by AT, then PID]
    
    // Non-preemptive execution: run to completion
    currentProcess.CT = currentTime + currentProcess.BT
    currentProcess.TAT = currentProcess.CT - currentProcess.AT
    currentProcess.WT = currentProcess.TAT - currentProcess.BT
    currentProcess.completed = true
    
    currentTime = currentProcess.CT
    completed++
Pseudo-Code: Round Robin (RR)
currentTime = 0, ReadyQueue = empty
Enqueue all processes arriving at t = 0 into ReadyQueue

While (ReadyQueue is not empty OR uncompleted processes remain):
    If ReadyQueue is empty:
        currentTime = next process arrival time
        Enqueue arriving processes
        Continue

    P = ReadyQueue.dequeue()
    execSlice = min(Quantum, P.remainingBurst)
    
    currentTime += execSlice
    P.remainingBurst -= execSlice

    // Enqueue any newly arrived processes during this execution slice
    For each process arrived at or before currentTime:
        Enqueue into ReadyQueue

    If P.remainingBurst == 0:
        P.CT = currentTime
        P.TAT = P.CT - P.AT
        P.WT = P.TAT - P.BT
        P.completed = true
    Else:
        ReadyQueue.enqueue(P) // append preempted process to back of queue

Production C Implementations

cpu_sjf.c (Shortest Job First) 
#include <stdio.h>
#include <stdbool.h>

struct Process {
    int pid;
    int at;  // Arrival Time
    int bt;  // Burst Time
    int ct;  // Completion Time
    int tat; // Turnaround Time
    int wt;  // Waiting Time
    bool completed;
};

int main() {
    int n = 5;
    struct Process p[] = {
        {1, 0, 5, 0, 0, 0, false},
        {2, 1, 3, 0, 0, 0, false},
        {3, 2, 8, 0, 0, 0, false},
        {4, 3, 2, 0, 0, 0, false},
        {5, 4, 4, 0, 0, 0, false}
    };

    int currentTime = 0, completedCount = 0;
    float totalTAT = 0, totalWT = 0;

    printf("\n=== SJF (Non-Preemptive) Execution ===\n");

    while (completedCount < n) {
        int shortestIdx = -1;
        int minBurst = 999999;

        for (int i = 0; i < n; i++) {
            if (p[i].at <= currentTime && !p[i].completed) {
                if (p[i].bt < minBurst) {
                    minBurst = p[i].bt;
                    shortestIdx = i;
                } else if (p[i].bt == minBurst) {
                    if (p[i].at < p[shortestIdx].at) shortestIdx = i;
                }
            }
        }

        if (shortestIdx == -1) {
            currentTime++; // CPU Idle
            continue;
        }

        int idx = shortestIdx;
        currentTime += p[idx].bt;
        p[idx].ct = currentTime;
        p[idx].tat = p[idx].ct - p[idx].at;
        p[idx].wt = p[idx].tat - p[idx].bt;
        p[idx].completed = true;
        completedCount++;

        totalTAT += p[idx].tat;
        totalWT += p[idx].wt;
    }

    printf("PID\tAT\tBT\tCT\tTAT\tWT\n");
    for (int i = 0; i < n; i++) {
        printf("P%d\t%d\t%d\t%d\t%d\t%d\n", p[i].pid, p[i].at, p[i].bt, p[i].ct, p[i].tat, p[i].wt);
    }

    printf("\nAverage Turnaround Time = %.2f\n", totalTAT / n);
    printf("Average Waiting Time    = %.2f\n", totalWT / n);
    return 0;
}
cpu_round_robin.c (Round Robin) 
#include <stdio.h>
#include <stdbool.h>

struct Process {
    int pid;
    int at;
    int bt;
    int rem_bt;
    int ct;
    int tat;
    int wt;
};

int main() {
    int n = 4, quantum = 2;
    struct Process p[] = {
        {1, 0, 5, 5, 0, 0, 0},
        {2, 1, 4, 4, 0, 0, 0},
        {3, 2, 2, 2, 0, 0, 0},
        {4, 4, 1, 1, 0, 0, 0}
    };

    int currentTime = 0, completed = 0;
    int queue[100], front = 0, rear = 0;
    bool inQueue[10] = {false};

    for (int i = 0; i < n; i++) {
        if (p[i].at <= currentTime && !inQueue[i]) {
            queue[rear++] = i;
            inQueue[i] = true;
        }
    }

    while (completed < n) {
        if (front == rear) {
            currentTime++;
            for (int i = 0; i < n; i++) {
                if (p[i].at <= currentTime && !inQueue[i] && p[i].rem_bt > 0) {
                    queue[rear++] = i;
                    inQueue[i] = true;
                }
            }
            continue;
        }

        int curr = queue[front++];
        int slice = (p[curr].rem_bt > quantum) ? quantum : p[curr].rem_bt;

        p[curr].rem_bt -= slice;
        currentTime += slice;

        // Check arrivals
        for (int i = 0; i < n; i++) {
            if (p[i].at <= currentTime && !inQueue[i] && p[i].rem_bt > 0) {
                queue[rear++] = i;
                inQueue[i] = true;
            }
        }

        if (p[curr].rem_bt > 0) {
            queue[rear++] = curr;
        } else {
            p[curr].ct = currentTime;
            p[curr].tat = p[curr].ct - p[curr].at;
            p[curr].wt = p[curr].tat - p[curr].bt;
            completed++;
        }
    }

    printf("\n--- Round Robin Results (Q = %d) ---\n", quantum);
    printf("PID\tAT\tBT\tCT\tTAT\tWT\n");
    float avgTAT = 0, avgWT = 0;
    for (int i = 0; i < n; i++) {
        printf("P%d\t%d\t%d\t%d\t%d\t%d\n", p[i].pid, p[i].at, p[i].bt, p[i].ct, p[i].tat, p[i].wt);
        avgTAT += p[i].tat;
        avgWT += p[i].wt;
    }
    printf("Average Turnaround Time = %.2f\n", avgTAT / n);
    printf("Average Waiting Time    = %.2f\n", avgWT / n);
    return 0;
}

Frequently Asked OS Lab Viva Voce Questions

1. What is the Convoy Effect and which scheduling algorithm is susceptible to it? ▼
The Convoy Effect occurs in First-Come, First-Served (FCFS) scheduling when a long CPU-bound process occupies the CPU for a large burst, forcing many short I/O-bound processes to wait behind it. This degrades overall CPU utilization, device utilization, and sharply raises average waiting time.
2. Why is SJF / SRTF provably optimal for minimizing Average Waiting Time? ▼
By scheduling the shortest burst first, the waiting time of the shorter process is eliminated or reduced by a greater amount than the increase in waiting time added to the longer process. Consequently, the global sum of waiting times is mathematically minimized.
3. What is Starvation and how does Aging solve it? ▼
Starvation (indefinite blocking) occurs when a process is ready to run but never gets CPU time because higher-priority or shorter jobs keep arriving. Aging solves this by dynamically incrementing the priority of waiting processes as time progresses, guaranteeing that every process eventually reaches the highest priority.
4. What criteria govern the selection of Time Quantum Q in Round Robin? ▼
If Q is too large, Round Robin degenerates into FCFS, hurting response time. If Q is too small, context-switch overhead (saving registers, reloading state, cache misses) consumes an excessive percentage of total CPU time. The empirical rule of thumb is that approximately 80% of CPU bursts should be shorter than Q.
5. Differentiate between Turnaround Time, Waiting Time, and Response Time. ▼
Turnaround Time (TAT): Elapsed duration from process arrival to final completion (CT - AT).
Waiting Time (WT): Total time the process spends waiting in the ready queue without CPU access (TAT - BT).
Response Time (RT): Elapsed time from process submission (AT) until it is first allocated to the CPU.
6. How does Multi-Level Feedback Queue (MLFQ) achieve both responsiveness and fairness? ▼
MLFQ employs multiple priority queues with increasing time quanta. New jobs start at the topmost queue (short quantum) and are demoted to lower queues if they exhaust their time slice. This ensures short interactive jobs finish quickly, while long batch jobs run efficiently in lower tiers with FCFS or larger slices. Aging periodically elevates starved processes to the top tier.
